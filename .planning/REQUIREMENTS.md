# Requirements: Riccardo La Malfa Portfolio

**Defined:** 2026-04-10
**Core Value:** A recruiter can understand Riccardo's positioning and know how to contact him within one minute.

## v1 Requirements

Requirements for milestone v1.0. Each maps to exactly one roadmap phase.

### Content Foundation

- [ ] **CONT-01**: Maintainer can update hero, summary, skills, experience, education, languages, relocation, and contact content from a shared structured source.
- [ ] **CONT-02**: The one-page portfolio can render the shared content without hardcoded section copy directly inside the page layout.

### Hero and Positioning

- [ ] **HERO-01**: Visitor can immediately see Riccardo La Malfa's name and frontend-focused full-stack developer positioning.
- [ ] **HERO-02**: Visitor can understand Riccardo's professional summary within a short scan.
- [ ] **HERO-03**: Visitor can see Italy location context and EU relocation availability.

### Credentials

- [ ] **SKIL-01**: Visitor can scan core skills grouped by frontend, backend, DevOps, and databases.
- [ ] **EXPR-01**: Visitor can review professional experience with role, company, dates, and concise highlights.
- [ ] **EXPR-02**: Visitor can review education and languages on the same page.

### Contact

- [ ] **CNTC-01**: Visitor can use a clear primary CTA to contact Riccardo by email.
- [ ] **CNTC-02**: Visitor can open Riccardo's GitHub profile from the page.
- [ ] **CNTC-03**: Visitor can open Riccardo's LinkedIn profile from the page.

### Portfolio UX

- [ ] **PORT-01**: Visitor can use the one-page portfolio comfortably on mobile and desktop.
- [ ] **PORT-02**: Visitor can scan the page as a single narrative from introduction to contact CTA.

## v2 Requirements

Deferred beyond milestone v1.0.

### Future Enhancements

- **PROJ-01**: Visitor can browse featured project cards.
- **PROJ-02**: Visitor can open detailed project case-study content.
- **CV-01**: Visitor can view or download Riccardo's CV from the site.
- **UI-01**: Visitor can switch between multiple portfolio UI variants using the same content.

## Out of Scope

Explicitly excluded for milestone v1.0.

| Feature | Reason |
|---------|--------|
| Project showcase | Keep the first release focused on positioning and contact conversion. |
| Direct CV download/view | Use the CV as source content first; add file access later if still needed. |
| Multiple switchable UIs | Preserve future flexibility without expanding v1.0 implementation scope. |
| Multi-page structure | One page is enough for the first recruiter-focused release. |
