# Milestone v1.0.1 — Content source migration

**Status:** ✅ Solved 2026-04-30

## Summary

This tiny milestone formalizes the migration of the portfolio source-of-truth from the authored markdown (`public/assets/cv.md`) to a structured JSON payload (`public/assets/cv.json`) consumed at runtime.

## Motivation

- Static JSON simplifies server-side loading, avoids runtime markdown parsing, and makes regression/testing deterministic.

## What changed

- Added `public/assets/cv.json` containing the `PortfolioContent` shape.
- Updated `src/content/portfolio/get-portfolio-content.ts` to read `cv.json`.
- Updated tests to assert the JSON source where appropriate.
- Archived the markdown source in planning notes and retained `parse-cv.ts` as a utility for offline editing if needed.

## Evidence

- `public/assets/cv.json` present in the repo and parsed successfully by the loader.
- Quick-task summary: `.planning/quick/260412-grk-transform-public-assets-cv-md-into-json/260412-grk-SUMMARY.md` documents the change and the validating checks.

## Next steps (optional)

- If desired, delete the legacy `public/assets/cv.md` file and remove any remaining references, or keep it as an editable source that can be regenerated into `cv.json` via automation.
