# Phase 6 Plan 01: Knowledge map feature decomposition

## Objective
- **What:** Split the knowledge map into model, runtime, and UI layers.
- **Why:** The current hotspot is too monolithic to evolve safely.
- **Output:** Separate graph/selection/runtime/UI modules wired through a small feature entrypoint.
