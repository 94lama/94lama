| Property | Value |
|----------|-------|

| Font | Geist Sans as the primary family, Geist Mono only for restrained metadata or label treatment |

Design source:
- REQUIREMENTS.md and ROADMAP.md set the recruiter-first, single-page narrative goal.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Eyebrow label gaps, inline separators, chip internals |
| sm | 8px | Compact text stacks, metadata spacing |
| md | 16px | Default card padding, paragraph and list spacing |
| lg | 24px | Section internals, grouped content blocks |
| xl | 32px | Card-to-card gaps, paired panel spacing |
| 2xl | 48px | Major section breaks on mobile |
| 3xl | 64px | Major section breaks on desktop and hero-to-body transition |

Exceptions: minimum 44px touch target height for interactive links or buttons where applicable; this is an accessibility floor, not a new spacing token.

---

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 600 | 1.2 |
| Heading | 24px | 600 | 1.2 |
| Display | 56px | 600 | 1.1 |

Type rules:
- Body copy stays at 16px minimum on mobile for comfortable recruiter scanning.
- Display type carries the hero name and role emphasis; it can scale up responsively on larger screens, but the contract anchor is 56px.
- Labels are uppercase or tightly tracked only for short metadata, section markers, and chips.
- Do not introduce a third font weight or a fifth size in this phase.

---

## Visual Hierarchy

- Primary focal point: the hero name and role block at the top of the page.
- Secondary focal point: grouped credentials, with experience carrying the highest visual weight after the hero.
- Narrative scan order: hero and positioning, skills, experience, education and languages, relocation support, then contact.
- Contrast strategy: dark page shell with lighter panels and restrained accent hits so the page feels editorial rather than template-like.
- Section rhythm: alternate between open text-led areas and denser bordered or paneled credential blocks to keep the scroll visually varied.
- Accessibility fallback: avoid icon-only actions in this phase; if any icon treatment is added later, it must keep adjacent text labels or an explicit accessible name.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #0C0C0F | Page background, primary surfaces, hero field |
| Secondary (30%) | #171A22 | Cards, section panels, grouped content containers, dividers |
| Accent (10%) | #B8FF20 | Primary CTA, key chips, active inline links, focus ring, section index markers |
| Destructive | #FF5A54 | Reserved for destructive actions only if introduced in a later phase |

Color split: 60 percent dominant, 30 percent secondary, 10 percent accent.

Accent reserved for: primary email CTA, relocation availability chip, active or emphasized inline links, section markers, and visible keyboard focus rings only.

Do not use the accent on every border, heading, or interactive element. Neutral text and panel contrast should carry most of the hierarchy.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Email Riccardo |
| Empty state heading | No portfolio details available yet |
| Empty state body | Refresh the page or contact Riccardo directly by email for the latest profile. |
| Error state | Portfolio content could not load. Refresh the page, and if the problem continues, email Riccardo directly. |
| Destructive confirmation | none |

Copy rules:
- Hero supporting copy should sound credible and concise, not promotional or startup-generic.
- Section labels should be short nouns, not marketing phrases.
- Date, location, and relocation metadata should stay plain and instantly scannable.
- No destructive actions are in scope for Phase 2.
