| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | T | `src/content/portfolio/parse-cv.ts` | mitigate | Parse explicit section markers and known line formats, return typed fields only, and avoid permissive raw HTML handling. |
| T-01-02 | D | `src/content/portfolio/get-portfolio-content.ts` | mitigate | Fail fast with a clear error if `cv.md` is missing or malformed instead of silently returning partial unusable content. |
| T-01-03 | I | server-rendered content strings | mitigate | Render parsed values as plain React text only; do not use `dangerouslySetInnerHTML` for markdown content. |
